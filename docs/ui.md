# 웹 화면과 동작

한국어 UI는 흰색 바탕, 차콜 본문, 절제한 녹색 버튼을 사용합니다. 홈은 검색창과 프로젝트를 중심으로 정리하고 학습 수준·목표, 샘플, 모델·데이터·시간 추정은 접어서 보여줍니다. 브랜드는 `@cutling/shared`의 BRAND에서 읽습니다.

| 주소 | 기능 |
| --- | --- |
| `/` | 검색 목적·학습 수준·목표 설정, 프로젝트 생성, 실제 네이버 검색 열기, 명시적 데모 시작 |
| `/projects` | 이 브라우저의 프로젝트 목록 |
| `/projects/:id` | 자료·학습 단계·필기 실제 개수, 다음 검색, 최근 자료 |
| `/archive?project=ID` | 제목·본문 요약·출처·메모·태그 검색, 중요 표시, 카드·목록 전환, URL·클립보드 주소·본문 저장 |
| `/archive/:id?project=ID` | 3줄 요약과 근거 문단 링크, 원문, 메모·태그, 재수집·재요약, 삭제, Markdown 내보내기 |
| `/roadmap?project=ID` | 초안/자료 기반 구분, 단계 완료, 관련 자료, 메모, 다음 검색, 갱신 |
| `/notes?project=ID` | 이미지 파일 선택·드롭, 실제 업로드, OCR 결과 수정, 직접 입력 대안, 전송 동의, 정리·단계 연결 |
| `/report?project=ID` | 프로젝트 이벤트 집계, 시간 추정의 가정, 실제 모델 로그, 사용량 미제공·비교 불가 표시, 합성 샘플 평가 |
| `/settings` | 확장 프로그램 연결 코드, 연결 해제, HCX 실제 연결 진단, 신규 프로젝트 모드, 필터·시간 가정, 데이터 삭제 |
| `/demo?project=ID` | 데모 프로젝트 전용 합성 검색 결과, 목적 변경, 실제 분류 API, 필터 끄기, 다시 보기·유용함 피드백, 자료 저장 |

네이버는 별도 실제 탭으로 열립니다. 확장 프로그램 브리지가 연결되어 있으면 검색 세션과 프로젝트를 전달합니다. 브리지가 없으면 일반 검색 탭을 엽니다. 0.2.0 확장이 설치되어 있으면 연결 없이도 기본 필터가 실행되며, 저장 기능만 웹 연결이 필요합니다. 네이버를 iframe에 넣지 않습니다.

현재 브라우저의 연결 표시는 `CONNECT_STATUS` 핸드셰이크로 확인합니다. 응답 대기, 응답 미확인, 설치 확인·연결 필요, 현재 브라우저 연결됨을 구분하며, 응답 시간 초과를 미설치로 단정하지 않습니다. 서버의 유효한 연결 기록은 별도로 표시하고 연결 폐기에 사용합니다. 기본 데이터를 다시 불러오거나 창으로 돌아올 때 브라우저 상태를 재확인합니다.

클라이언트는 서버 API만 호출합니다. HCX 키나 HCX 클라이언트를 가져오지 않습니다. React 텍스트 렌더링으로 자료와 모델 출력을 표시하며 임의 HTML을 삽입하지 않습니다.

## 화면 검증

2026-10-13, Chromium의 1440px 데스크톱과 390px 모바일에서 `node scripts/ui-qa.mjs`를 실행했습니다. 최종 PNG는 `pnpm build` / `pnpm start` 프로덕션 서버에서 갱신했습니다. 홈, 데모 생성, 합성 검색 분석, 필기 빈 상태, 리포트를 탐색하고 확장이 없는 브라우저에서 응답 미확인 안내를 확인했습니다. 브라우저 예외 0개, 모바일 가로 넘침 없음. 결과는 `docs/screenshots/ui-checks.json` 및 같은 폴더의 PNG에 있습니다. 실제 네이버와 설치된 확장 프로그램의 수동 검증을 대체하지 않습니다.

키보드 포커스 표시, 본문 바로가기, 모달 포커스 제한·Escape 닫기, 상태 알림, 버튼 상태 라벨, 모바일 메뉴를 제공합니다. OCR이 실패해도 필기 텍스트를 입력하고 정리할 수 있습니다. 네트워크 오류는 설명과 재시도 또는 다시 실행할 수 있는 동작으로 표시합니다.

`tests/e2e/ui.spec.ts`는 API를 직접 조작하지 않고 홈 기본값(빈 선택 목표 포함)으로 프로젝트를 만든 뒤, 대화상자에서 본문을 저장하고, 세 줄 요약을 확인하고, 메모와 단계 완료 상태가 새로고침 후에도 유지되는지 검증합니다. Chromium에서 1개 테스트 통과. 클립보드 읽기는 사용자가 버튼을 눌렀을 때만 요청하고, HTTP(S) 주소가 아니거나 읽기 권한이 없으면 수동 입력을 안내합니다. 학습 수준은 기본 선택지와 직접 입력을 모두 지원합니다.
