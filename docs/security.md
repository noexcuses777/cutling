# 로컬 MVP 보안 경계

- 서버는 loopback 바인딩, Host 및 웹 Origin을 검사합니다. 기본 localhost:3000/127.0.0.1:3000 외 주소는 서버 설정이 필요합니다. 공개 배포에는 별도 로그인/접근 제한/TLS가 필요합니다.
- 웹 세션은 HttpOnly SameSite=Strict, HTTPS에서 Secure, 30일입니다. 확장 토큰은 랜덤 256비트, 해시만 DB에 보관, 연결 당시 chrome-extension origin에 묶고 30일 만료합니다. 일회용 연결 코드는 5분 유효하며 원자적으로 소비합니다. 확장은 자기 토큰을, 웹은 모든 자기 연결을 폐기할 수 있습니다.
- Chrome 확장 worker의 GET은 Origin 헤더를 생략할 수 있습니다. 이 경우 저장된 origin과 `X-Cutling-Extension-ID`가 일치하는지 확인하고 유효한 Bearer 토큰을 함께 요구합니다. Origin이 있으면 반드시 연결 당시 origin과 일치해야 합니다. 확장 ID 자체를 인증 비밀로 취급하지 않습니다.
- 모든 API는 인증 뒤 ownerId와 프로젝트 소유권을 검증합니다. CORS 자체를 인증으로 쓰지 않습니다. 기본 요청 200KB, 결과 배치 30개, 업로드 5MB, 사용자/연결 rate limit이 있습니다.
- 웹 브리지는 정확한 origin, 같은 window, 메시지 스키마, 허용 동작과 requestId를 검사합니다. 페이지 JS에 Bearer 토큰이나 HCX 키를 보내지 않습니다. 토큰은 확장 trusted contexts만 접근 가능한 chrome.storage에 있습니다.
- 외부 본문은 사용자 저장 요청에 한해 수집합니다. HTTP(S), 포트80/443, 공인 IP만 허용합니다. DNS 모든 결과와 리다이렉트를 확인하며 검증된 IP로 연결을 고정합니다. 타임아웃12초, 본문1MB, 이동3회, 텍스트 MIME만 허용합니다. 로그인/CAPTCHA/유료벽은 우회하지 않습니다.
- Sharp로 실제 이미지 형식·픽셀·크기를 검사하고 PNG로 다시 인코딩합니다. 파일은 무작위 이름으로 private data/uploads 아래 저장하며 소유권 API만 제공합니다. 외부 스크립트나 HTML을 실행하지 않습니다.
- React와 DOM textContent로 원문/AI 출력 텍스트를 표시합니다. raw HTML/Markdown HTML 렌더링이 없습니다. 프롬프트는 외부 문서를 명령이 아닌 데이터로 구분하고 출력 스키마·근거 문단·ID를 검증합니다. 이는 프롬프트 공격을 완전히 제거한다는 보장은 아닙니다.
- 요청/오류 로그는 키·인증 헤더·본문 전문을 출력하지 않습니다. 개인 필기는 공유 캐시를 쓰지 않으며 다른 요약/분류 캐시는 ownerId로 범위를 나눕니다.
- 필기 외부 전송 동의는 검토한 텍스트의 해시에 연결됩니다. 수정하면 이전 동의를 해제하며, 대기 작업은 호출 전·저장 전에 해당 버전과 동의를 확인합니다. 이미 전송을 시작한 이전 버전의 요청은 회수할 수 없지만 변경된 텍스트를 같은 동의로 보내지 않습니다.
- 데이터 삭제는 작업·자료·노트 파일·모델 로그·확장 토큰을 포함합니다. 실행 중 외부 요청의 이미 전송된 데이터까지 회수할 수는 없습니다. 운영 중 DB/업로드 백업 정책은 별도입니다.
