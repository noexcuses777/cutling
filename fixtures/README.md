# 합성 평가 자료

`search-results.ts`에는 15개 결과 유형과 목적에 따라 정답이 달라지는 6개 사례가 있습니다. 제목·요약·날짜는 모두 테스트용으로 작성했습니다. `example.org` URL은 본문을 가져올 대상으로 사용하지 않습니다. 파이썬 공식 문서 주소는 공개 출처의 도메인 인식 테스트에만 사용합니다. 이 fixture의 통과율은 네이버 전체 검색의 정확도가 아닙니다.

`demoText`는 저작권 문제가 없는 직접 작성한 짧은 학습 텍스트입니다. 데모 데이터는 사용자가 데모 시작을 선택한 경우에만 생성합니다. OCR 샘플은 사용자가 직접 작성한 PNG/JPG/WEBP 필기를 업로드하거나 인식 텍스트를 직접 입력해 검증할 수 있습니다.
